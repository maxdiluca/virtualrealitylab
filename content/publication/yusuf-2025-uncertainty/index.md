abstract: The paper combines Bayesian belief networks and a large language model to interpret uncertain information
  from UAV sensors. Forest-fire detection motivates the work, with laboratory demonstrations using non-combustible
  objects. Visual features and language-model interpretations are represented within a network whose conditional
  probabilities incorporate expert input. The implementation uses a DJI Ryze Tello and PyBBN to explore flexible,
  real-time sensor interpretation.
